한장 개인정보처리방침

시행일: 2026년 11월 16일

'한장'(https://woobin-1018.github.io/hanjang/, 이하 "서비스")은 AI로 발표자료를 만들어 주는 개인 프로젝트입니다. 서비스는 아래와 같이 최소한의 정보만 다룹니다.

1. 받는 정보

  • Google 로그인 시 받는 이메일 주소와 이름
  • 계정별 하루 생성 횟수와 이용 시각 (하루 이용 횟수를 제한하기 위한 기록)

2. 쓰는 곳

  • 로그인한 사용자 확인과 하루 이용 횟수 제한에만 씁니다.
  • 광고, 마케팅, 제3자 판매에 쓰지 않습니다.

3. 입력한 내용과 만든 발표자료

  • 사용자가 입력한 주제·자료는 발표자료를 만들기 위해 Anthropic의 Claude API로 보내집니다. 처리 방식은 Anthropic 개인정보처리방침을 따릅니다.
  • 만든 발표자료는 서비스 서버에 저장하지 않습니다. 사용자의 브라우저에만 있으며, 내려받지 않으면 화면을 닫을 때 사라집니다.

4. 맡기는 곳

  • Supabase: 로그인 처리와 이용 횟수 기록 (서울 지역 서버)
  • Google: 로그인
  • Anthropic: 발표자료 내용 생성
  • GitHub Pages: 웹페이지 제공

5. 보관 기간과 삭제

  • 이용 기록은 서비스 운영 기간 동안 보관하며, 서비스를 끝내면 모두 지웁니다.
